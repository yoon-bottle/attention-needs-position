# Attention needs position
Approved direction: English interactive article, under 1,200 words excluding references, comparing unmasked self-attention with and without positional encodings. Tokens reorder together in both panels. Position labels stay attached to slots; a secondary experiment moves position vectors with tokens. Use actual deterministic toy calculations, not a trained semantic model. Never infer understanding from vector change.

Design: cool paper #f5f7fc, ink #17264b, blue #345ce6, teal #087e86, muted #63708a. Georgia display, system sans body, monospace numerical captions. Signature: movable word cards above paired output fingerprints and weighted connection lines. On small screens panels stack. Keyboard arrow moves and explicit buttons complement pointer drag. Reduced motion is respected.

Architecture: buildless static site, shared pure attention module, DOM controller, CSS. Fixed 8-dimensional embeddings and projections, sinusoidal positions, stable row softmax, no causal mask. Baseline comparisons align by token identity. Numerical tests cover all permutations and position-vector movement. Public repository requested under yoon-bottle; GitHub Pages branch deployment. No lecture PDF or private chat logs in public repository.
