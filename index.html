Same words.
Different meaning.

A dog bites a man. A man bites a dog.
You notice the difference. Does attention?

Move the words and find out ↓

The missing ingredient is order.

Self-attention lets each token collect information from other tokens. But without position information or a mask, it has a surprising blind spot: rearranging the inputs only rearranges the outputs. The computation does not distinguish who came first.

My question for this experiment is simple: what changes when a word changes seats? Try swapping “dog” and “man.” Predict what will happen to each word’s output before you move it.

One more experiment: move the seat labels, too.

Normally, positions stay with their slots. What if each word takes its original position vector along when it moves?

Reorder again. This moves the entire word–position pair, so we are back to a permutation of the same input vectors. The outputs follow their words again.

Follow the word, not the slot.

A picture of an attention matrix can change just because its rows and columns moved. That is why this experiment compares each word with itself in the original sentence. With position off, “dog” keeps its output even when it changes seats. This is permutation equivariance, not invariance: the output sequence moves with the input sequence.

Attention(PX) = P Attention(X)

Here, X contains the token vectors, and P rearranges their rows. Shared query, key, and value projections preserve that rearrangement. The score matrix is reordered on both axes; row-wise softmax preserves those corresponding weights. The weighted sums therefore follow the same tokens.

Give each seat an address.

With position on, a token receives xᵢ = eᵢ + pᵢ: its word embedding plus its position vector. Moving “dog” now changes its input, queries, keys, and values. Attention can consequently produce a different output for the same word.

This demo uses sinusoidal position vectors: pairs of sine and cosine waves at different frequencies. The important distinction here is not the particular waves. It is that the position belongs to the seat, while the word can move.

The extra experiment tests that explanation. Carrying the position vector with its word removes the intervention: we are rearranging unchanged word–position pairs. Equivariance returns.

A changed vector is not understanding.

This is a deterministic, untrained, single-head attention calculation with eight-dimensional vectors. It uses scaled dot-product attention, fixed illustrative embeddings and projections, and no causal mask. Both panels share those embeddings and projections. Every displayed weight and output is computed, not drawn from a language model.

Position information makes order-sensitive representations possible; training must still make them useful. A changing color strip does not prove the model knows who bit whom. Also, our no-position result is about unmasked attention: a causal mask itself introduces an ordering constraint.

The takeaway I want to test is narrower and more useful: attention can compare token content, but it needs an order signal to treat a change of seats as more than a rearrangement.
